## 📚 Core Algorithmic Patterns

### 1. Two Pointers
- **Use Case**: Sorted arrays, finding pairs that meet a condition, palindrome checks, in-place partitioning.
- **Classic Problems**: Valid Palindrome, Two Sum II (Sorted), 3Sum, Container With Most Water.

### 2. Sliding Window
- **Use Case**: Contiguous subarrays or substrings with optimal length or sum.
- **Classic Problems**: Longest Substring Without Repeating Characters, Minimum Size Subarray Sum, Maximum Sum Subarray of Size K.

### 3. Fast & Slow Pointers (Floyd's Tortoise & Hare)
- **Use Case**: Cycle detection in Linked Lists, finding the middle of a linked list.
- **Classic Problems**: Linked List Cycle, Middle of the Linked List, Happy Number.

### 4. Tree & Graph Traversals (BFS / DFS)
- **Use Case**: Hierarchical data, shortest paths, connected components.
- **Classic Problems**: Maximum Depth of Binary Tree, Binary Tree Level Order Traversal, Invert Binary Tree, Number of Islands.

### 5. Dynamic Programming (1D)
- **Use Case**: Overlapping subproblems and optimal substructure.
- **Classic Problems**: Climbing Stairs, Coin Change, House Robber, Longest Increasing Subsequence.
